# 子 agent 与会话的统一改造 · ⑦：会话面板里的 Ctrl+X 与等审批标记（基线 b06cb1f）

457 不分段，接着做剩下的四项；本块是其中两项：面板里 Ctrl+X 的两下语义、使用者不在某个会话时它（含它的子 agent）等审批的标记。细化记为决策 483。

## 一、改动

| 文件 | 内容 |
| --- | --- |
| `src/application/session-pool.ts` | `stop` 改为只停这一轮：在跑的中断，运行面不释放，记为人停下的（不被后台作业、子 agent 交回的结果叫醒）；新增 `remove`：从面板去掉并释放运行面（面板会话的 `close` 里注销通讯录，它派出的子 agent 一并停下），还在开的开完即释放；`send` 给停下的会话即接着干（停着期间排着的通知随这一轮一并交给它）；`take` 对停下的会话按还开着取；关掉 Pigeon 时逐个释放；卡片的"等待回应"在停下的会话里也标，答完回到已停（没停的答完按在不在跑回到在跑或空闲，原来一律回到在跑） |
| `src/tui/shell.ts` | 面板里别的会话的 Ctrl+X：第一下停下（不再先提示），两秒内再按一下从面板去掉；已停下的第一下只等第二下。当前会话那张卡照 458（连按两下中断这一轮），间隔同为两秒。当前会话那张卡在它的子 agent 等审批时标等待回应 |
| 测试 | `session-pool.test.ts`、`main-pool.test.ts`、`session-panel.test.ts` 改写按旧语义（停下即释放）的断言；新增：停下的会话不被叫醒、收到话即接着干、去掉才释放；停下的会话里子 agent 等审批照样标出；当前会话那张卡因子 agent 等审批标出 |
| 文档 | `docs/configuration.md` 会话面板一节与键位表、子 agent 一节；决策 483 与索引行；443 标部分已改 |

## 二、工程上的取舍

- 停下的会话照样可以 `/take`，按还开着取（起点前移、工作树留着）；工作树的清理挪到从面板去掉时（没有改动即删，有改动保留），原来是"已停的会话完整取回即删工作树"。会话还能接着干，删了工作树就接不上。
- 当前会话那张卡连按两下的间隔由 1.5 秒改为 2 秒，与别的会话"两秒内再按一下"一致。
- 停下的会话第一下 Ctrl+X 不出提示，只等第二下（照"界面不加提醒"）；当前会话那张卡原有的"再按一次即中断"提示保留（458 的做法）。
- "去掉"只去掉本进程面板上这一行；跨工作区的工作清单（用户级索引）在⑨里接上，届时去掉同时删出索引。
